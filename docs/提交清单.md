## 三、提交前十分钟自检

```bash
# 1. 干净环境能跑
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python -m duban init            # 期望：7 篇 / 275 个片段
python -m duban ask "Raft 的 Figure 8 说明了什么问题？"

# 2. 测试与评测
python -m pytest                # 期望：9 passed
python -m duban eval            # 期望：Hit@3 ≈ 0.90，citation_valid = 1.0

# 3. 界面
python -m duban serve           # 打开 http://127.0.0.1:8765
```

| 检查项 | 通过标准 |
| --- | --- |
| 仓库里没有密钥 | `git grep -nE "sk-[A-Za-z0-9]{10,}|api_key|token"` 无命中（除文档里的占位说明） |
| 没有提交数据库与缓存 | `.gitignore` 覆盖 `.runtime/`、`__pycache__/`、`.pytest_cache/` |
| 语料可分发 | 两篇论文是公开 PDF，README 已注明来源 |
| 站点公开 | 无痕窗口可打开 |
| 记录齐全 | `records/qoder/` 至少 6 张截图 + UID |
